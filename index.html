ℹ️ How the numbers work

Current attendance % = (classes attended ÷ classes conducted) × 100
Classes remaining = total classes (45) − classes conducted
Final attendance % = (attended + future classes attended) ÷ 45 × 100, since conducted + remaining = 45.
Classes needed for 75% = ⌈0.75 × 45⌉ − attended = 34 − attended
Classes needed for 90% = ⌈0.90 × 45⌉ − attended = 41 − attended
If the number needed is more than the classes remaining, the target is not reachable.
Below 75% - detention risk  |  75-90% - safe  |  90%+ - excellent
